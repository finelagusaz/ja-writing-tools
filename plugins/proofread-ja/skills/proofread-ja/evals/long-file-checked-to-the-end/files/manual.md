# 業務システム 操作マニュアル

このマニュアルは、業務システムを利用するユーザー向けに、各機能の操作方法をまとめたものです。

## 第1章 ログイン

この章では、ログイン機能の基本的な使い方を説明します。ログイン機能は、日々の業務でもっとも利用される機能のひとつです。初めて使う方は、この章を最初から順に読み進めてください。以外と知られていませんが、キーボードだけでも操作できます。すでに使ったことがある方は、必要な節だけを参照してもかまいません。

ログイン画面を開くには、画面左側のメニューから「ログイン」を選びます。メニューが表示されていない場合は、画面左上のボタンを押してメニューを開いてください。ユーザーの権限によっては、メニューに「ログイン」が表示されないことがあります。その場合は、管理者に権限の付与を依頼してください。

ログイン画面は、上部の操作バー、中央の一覧、右側の詳細パネルの三つの領域で構成されています。操作バーには、よく使う操作のボタンが並んでいます。一覧の行を選ぶと、右側の詳細パネルに内容が表示されます。詳細パネルの幅は、境界線をドラッグすることで調整できます。

ログインの設定を変更するには、操作バーの「設定」を押します。設定画面では、表示する項目、並び順、一ページあたりの件数を変更できます。変更した内容は、「保存」を押すまで反映されません。保存せずに画面を閉じると、変更は破棄されますので注意してください。

ログインの操作中にエラーが表示された場合は、まずメッセージの内容を確認してください。多くの場合、入力内容の不備か、権限の不足が原因です。メッセージに従って入力を見直しても解決しないときは、画面右上の「ヘルプ」から問い合わせフォームを開き、表示されたメッセージをそのまま貼り付けて送信してください。

ログイン機能の利用状況は、管理者が監査ログで確認できます。記録されるのは、操作した日時、操作の種類、対象のデータです。入力した内容そのものは記録されません。記録の保存期間は一年間で、期間を過ぎた記録は自動的に削除されます。
