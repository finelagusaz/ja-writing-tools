# ブログ・Web記事モード (Blog/Web)

## 文体ルール

*   **PREP法**: Point（結論）→ Reason（理由）→ Example（具体例）→ Point（結論）の流れを意識する。
*   **見出しの活用**: スクロールして読む読者のために、見出しだけで内容がわかるようにする。
*   **SEO意識**: キーワードを自然に盛り込むが、読みやすさを犠牲にしない。
*   **改行と空白**: 3〜4行ごとに改行を入れるなど、視覚的な圧迫感を減らす。
*   **CTA（行動喚起）**: 記事の終わりに読者に行動を促す一文を添える。（例：「ぜひ試してみてください」「コメントで教えてください」）

## チェックポイント

*   [ ] 「！」や「？」を使って読者に語りかけているか？（適度な距離感）
*   [ ] 一文が長すぎないか？（60文字以内推奨）
*   [ ] 漢字の含有率は適切か？（開きすぎず閉じすぎず、30-40%目安）
*   [ ] 専門用語を平易な言葉に言い換えられないか？

## 推敲パターン

### 親しみやすさの演出
*   **Before**: 本日は、新しい機能について説明します。
*   **After**: 今日は、待望の新機能について紹介しちゃいます！

### 呼びかけ
*   **Before**: 運動は健康に良いです。
*   **After**: 「最近、運動不足だな…」なんて感じていませんか？実は、運動って健康にすごく良いんです。

### 漢字を開く（ひらがなにする）
*   **Before**: 是非この機能を使って頂きたいと思って居ます。
*   **After**: ぜひこの機能を使っていただきたいと思っています。
*   **Before**: 予め全ての事を確認して下さい。
*   **After**: あらかじめすべてのことを確認してください。
