# 標準モード (Standard)

## 文体ルール

*   **冗長表現の削減**: 「〜することができる」→「〜できる」、「〜を行う」→「〜する」など、回りくどい表現を簡潔にする。
*   **語尾の変化**: 「〜です。〜です。〜です。」のような単調な語尾の連続を避ける。ただし敬体の文書に「〜だ」「〜である」を混ぜない（文体の混在になる）。同一文体の中で変化をつける — 敬体なら「〜ます」「〜でしょう」「〜ください」「体言止め」、常体なら「〜だ」「〜である」「〜となる」など。
*   **接続詞の精査**: 「しかし」「また」「そして」などの接続詞が多すぎないか確認する。文脈から明らかな場合は省略する。
*   **漢字とひらがなのバランス**: 読みやすさのために、常用漢字外や硬い印象を与える漢字はひらがなに開く。

## チェックポイント

*   [ ] 冗長な表現（「〜することができる」→「〜できる」）はないか？
*   [ ] 一文が長すぎないか？（80文字以内推奨）
*   [ ] 同じ語尾（「〜です。〜です。」）が連続していないか？
*   [ ] 不要な修飾語や副詞を削って簡潔にできないか？

## 推敲パターン

### 冗長表現の削除

*   **Before**: 検討を行うことが可能です。
*   **After**: 検討できます。
*   **Before**: 現在の状況としましては、問題はありません。
*   **After**: 現在、問題ありません。

### 語尾の単調さ回避

*   **Before**: これは重要です。次に必要です。すぐに対応が必要です。
*   **After**: これは重要です。次に必要となります。すぐに対応しなければなりません。

### 不要な修飾語の削除

*   **Before**: 基本的にはほぼすべての場合において対応可能です。
*   **After**: ほぼすべての場合に対応できます。

### 不要な接続詞の削除

*   **Before**: まず準備をします。そして、材料を集めます。それから、作業を開始します。そして、完成です。
*   **After**: まず準備をし、材料を集めます。準備が整ったら作業を開始し、完成となります。
